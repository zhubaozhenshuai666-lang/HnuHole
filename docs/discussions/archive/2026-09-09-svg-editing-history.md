# 正式设计稿的编辑方式

编辑工具为本机已安装的 **Inkscape 1.4.2**。这些文件是可编辑文字与矢量对象组成的 SVG，不是放在画布上的整张图片。

- 双状态总览（历史路径：`../../UI产品图/post-detail-dark-final.svg`，原文件现已不在该位置）
- 默认阅读（历史路径：`../../UI产品图/post-detail-read-final.svg`，原文件现已不在该位置）
- 展开评论（历史路径：`../../UI产品图/post-detail-comments-final.svg`，原文件现已不在该位置）
- 楼中楼结构放大图（历史路径：`../../UI产品图/post-detail-replies-detail-final.svg`，原文件现已不在该位置）

在 Inkscape 中使用“文件 → 打开”选择以上任一 SVG。使用文字工具点击文字进行修改；使用选择工具选取头像、图标或其他对象，可调整位置和颜色。“图层与对象”面板提供默认阅读、展开评论、正文、评论等分组。

保存 SVG 保留可编辑对象；需要图片时再导出 PNG。修改前可“另存为”新版本，正式基准稿与后续尝试便于区分。

原图中的上下分屏和滚动条是设计示意。编辑器内的裁剪保持预览外观，不模拟 App 滚动；完整的三条楼中楼与展开入口可在局部放大图中编辑查看。
