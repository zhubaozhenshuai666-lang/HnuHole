# 第十七轮设计十问：剩余产品边界（已回答）

状态：2026-09-16。用户第 1—9 项已回答：第 1、2、5、7、8、9、10 项采用建议；第 3 项补充“用户端可以取消这次上传、发布”；第 4 项改为本人评论直接滚到顶部；第 6 项改为待收消息一直保存、不能丢失。第 10 项已在此前轮次明确，本轮不应重复提问，已从当前决策中排除。

## 本轮结论

| 项 | 结论 |
| --- | --- |
| 1 | 登录会话固定三十天，活跃期间允许后台续期；主动退出或新设备接替立即失效。 |
| 2 | 点击获取验证码后，该控件立即变为六十秒倒计时；页面重开不重置。 |
| 3 | 发帖上传／发布处理中，用户端可以取消本次上传发布；取消后不公开为成功帖子。 |
| 4 | 本人评论发布成功后，评论区直接滚到顶部并定位该评论。 |
| 5 | 楼中楼展开更多按约五十条一页，保留当前位置，失败保留已展示内容。 |
| 6 | 离线待收消息由平台持续保存，不能因期限到期丢失；设备重新联网并登录后补收。 |
| 7 | 本地聊天保存失败时，在当前 App 运行期间保留临时内容并持续提示保存失败；退出 App 后不承诺保留。 |
| 8 | 申诉处理中可追加材料，不重新占用申诉次数；案件结案后不再追加。 |
| 9 | 热榜按五分钟短周期批量更新，停留期间不自动重排，重新进入或主动刷新时载入新排名。 |
| 10 | “常用标点具体放行哪些”此前已确认按 Unicode 标点类别放行，本轮不重复。 |

## 说明

第 3 项的“取消”只表示取消本次客户端上传／发布任务，不改变已经由服务端确认成功的帖子结果；客户端显示以服务端最终状态为准。第 6 项的持续保存指平台为待投递消息保留至接收方成功补收，不等同于平台提供完整聊天历史云存档。
