# 设计图交付记录

当前交付格式以[产品设计目录](README.md)的约定为准：优先 PNG，不强制可编辑，不要求 SVG/Inkscape。图片确认范围由所属模块维护。

早期曾因 Figma 额度受限转用 SVG；用户后来明确其电脑无法使用对应软件，并接受直接交付 PNG。此前的编辑说明仅作为[历史记录](../discussions/archive/2026-09-09-svg-editing-history.md)保存。

现有可用图稿见[帖子详情图稿档案](post-detail-dark-final.md)、[评论模块](modules/comments.md)和[身份模块](modules/identity.md)。
