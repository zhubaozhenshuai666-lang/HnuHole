# 仓库、认证与首条垂直切片

状态：accepted（2026-09-23）。项目使用单仓库 monorepo，包含 Flutter 客户端、Go 模块化单体、OpenAPI 契约、基础设施和文档；首版目标可能超过 10000 名用户，但用户规模不决定仓库拆分，运行时扩展由服务端部署、数据库和后续容量设计负责。数据库迁移使用 `goose`，OpenAPI 使用 `oapi-codegen`；登录采用服务端不透明会话令牌；本地开发由宿主机运行 Flutter/Go，Docker Compose 运行基础设施。第一条垂直切片验证文字内容主链，私信作为后续切片。

## 工程边界

- 初始仓库目录为 `apps/mobile`、`services/api`、`packages/openapi`、`infra` 和 `docs`；Go 服务端内部继续按领域模块组织。
- `goose` 迁移文件和 OpenAPI 源文件进入版本控制；不使用运行时自动建表。
- 邮箱验证码继续由隔离验证边界处理；社区业务服务接收验证成功后的内部账号标识。会话记录由服务端保存，令牌仅存于客户端系统安全存储，服务端支持设备替代、注销和封禁时立即撤销。
- 开发环境首阶段使用 PostgreSQL 与 Mailpit；CI、集成测试和部署基线见 [ADR 0004](0004-ci-testing-email-and-deployment.md)。图片对象存储和生产推送不进入第一条文字切片。

## 首条垂直切片验收范围

开发邮箱验证夹具登录、身份初始化、进入通道、发布文字帖子、阅读详情、发布主评论与楼中楼回复、在“我的”查看帖子和草稿，并验证帖内身份固定、不同身份隔离、API/迁移/OpenAPI 生成和基础测试可运行。私信发送、实时聊天、图片、推送、热榜、举报和申诉安排到后续切片。
